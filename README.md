# 🛡️ AI Phishing Email Detector

An AI-powered phishing email detection system that analyzes suspicious emails using **Google Gemini AI** and **VirusTotal**.

## 🌐 Live Demo

https://ai-phishing-email-detector0.streamlit.app

## 🚀 Features

- Detect phishing emails using Gemini AI.
- Scan embedded URLs with VirusTotal.
- Display phishing risk score.
- Display confidence score.
- Explain why an email is classified as phishing or safe.
- Generate downloadable TXT reports.
- Generate downloadable PDF reports.
- Web interface built with Streamlit.

## 🛠️ Technologies

- Python
- Streamlit
- Google Gemini API
- VirusTotal API
- ReportLab
- Requests

## 📂 Project Structure

```
web_app.py
phishing_backend.py
requirements.txt
```

```bash
pip install -r requirements.txt
streamlit run web_app.py
```
